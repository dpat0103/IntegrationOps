# IntegrationOps public description

## GitHub repository description

API health and incident monitoring: check external services, identify failures, and track recovery. Built with Python, FastAPI, Celery, Redis, and PostgreSQL.

## LinkedIn project description

Built IntegrationOps to monitor the external services an application depends on. It identifies API failures, records check history, and tracks incidents through recovery. The interactive demo lets visitors simulate an outage and watch the incident open and resolve.

The project demonstrates backend API design, asynchronous processing, failure handling, and operational monitoring using Python, FastAPI, SQLAlchemy, Celery, Redis, PostgreSQL, Prometheus, Grafana, Docker, and automated tests. The lightweight hosted demo uses SQLite and a local scheduler; the distributed architecture is supplied through Docker Compose.

## Claim boundaries
